# Advent of Code 2025 Solutions

Welcome to my solutions for **Advent of Code 2025**! This repository contains solutions to the programming puzzles from [Advent of Code](https://adventofcode.com/2025), implemented in **Rust** and **Python**.

## Repository Structure

The repository is organized by day, with each day's challenge having its own folder. Each folder contains the following:

- **`rs_d2/`**: Solutions implemented in Rust, including the `Cargo.toml` file for dependencies and the `src/main.rs` file for the solution.
- **`day_2.py`**: The Python solution for the day's challenge.
- **`input_d2_25.txt`**: The input data for the day's challenge.
- **`README`**: The puzzle description.
